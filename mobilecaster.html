Video codecs

H.264

Safest and most compatible. Works with every platform. Use this first.

Smaller file size, but less supported. Better for high-res streams later.

Audio codecs

Standard for RTMP/RTMPS. Use for YouTube, Facebook, Twitch.

Opus

Used in WebRTC and some SRT workflows. More efficient at low bitrates.

Activity vs Service — why it matters

❌ Bad: everything in MainActivity

Stream dies on screen rotation, app background, or orientation change. Beginner mistake.

✅ Good: split approach

MainActivity = UI only. StreamingService = engine. The stream survives because the service keeps running.

Adaptive bitrate logic

The app watches heat and network, then automatically adjusts bitrate to keep streaming stable.

The policy

class AdaptivePolicy {
  private val minBitrate = 800_000
  private val maxBitrate = 4_000_000

  fun nextBitrate(current: Int, weakNetwork: Boolean, hotPhone: Boolean): Int {
    return when {
      hotPhone → (current * 0.6).toInt().coerceAtLeast(minBitrate)
      weakNetwork → (current * 0.75).toInt().coerceAtLeast(minBitrate)
      else → (current * 1.1).toInt().coerceAtMost(maxBitrate)
    }
  }
}

Thermal states

Normal

Full bitrate. All systems go.

Moderate

Reduce bitrate slightly. Watch closely.

Severe

Force bitrate to 1.2 Mbps. Protect the phone.

OBS setup guide

Step-by-step to receive SRT from your phone in OBS Studio.

Find your computer IP

Windows

ipconfig

Look for "IPv4 Address" under your Wi-Fi adapter

Mac / Linux

ifconfig | grep inet

Look for 192.168.x.x or 10.x.x.x

Add SRT Media Source in OBS

In OBS: Sources → + → Media Source → uncheck "Local File"

srt://0.0.0.0:9999?mode=listener&latency=200000

OBS is the listener. It waits for the phone to connect.

Set phone app URL
srt://192.168.1.50:9999?mode=caller&latency=200000

Replace 192.168.1.50 with your actual computer IP. Phone is the caller.

The golden rule

OBS = listener  |  Phone = caller  |  Same Wi-Fi  |  OBS starts listening first

Common errors & fixes

The most frequent issues beginners hit when building and testing MobileCaster.

OBS shows black screen
  • ✦ Phone and computer are on the same Wi-Fi network
  • ✦ OBS firewall is allowed (Windows Firewall, macOS Firewall)
  • ✦ Correct computer IP address used in phone app
  • ✦ OBS is in listener mode before phone starts streaming
  • ✦ No other app is using port 9999
Stream starts then stops
  • ✦ Weak Wi-Fi signal — move closer to router
  • ✦ Bitrate too high for network — try 720p 2500 kbps
  • ✦ Phone overheating — cool it down, reduce bitrate
  • ✦ Firewall blocking UDP (SRT uses UDP)
  • ✦ Wrong SRT mode — check caller vs listener
Safe starting point: 720p · 30fps · 2500 kbps
YouTube / Facebook not working
  • ✦ Use RTMPS, not SRT or plain RTMP
  • ✦ Stream key is correct and copied exactly
  • ✦ Live event is created and set to "waiting for stream"
  • ✦ Full URL is entered including the stream key
iPhone stream stops when screen locks

This is expected behavior. iOS may suspend camera access when backgrounded.

  • ✦ Keep the app open and visible
  • ✦ Enable Screen Wake Lock in app settings
  • ✦ Plug the phone into power for long events
